# Assets Directory

This directory contains placeholder assets for the Expo app.

## Required Assets

To customize the app appearance, replace these placeholder files:

- **icon.png** - App icon (1024x1024 px recommended)
- **splash.png** - Splash screen image (1284x2778 px for iOS)
- **adaptive-icon.png** - Android adaptive icon (1024x1024 px)
- **favicon.png** - Web favicon (48x48 px or larger)

## Current Status

The current files are minimal placeholders. For production use, replace with proper branded assets.

## Generating Assets

You can use the following tools to generate app icons:
- https://icon.kitchen/
- https://www.appicon.co/
- Figma or other design tools
