# Expo Example App

Interactive showcase for RN Unified UI components.

## Getting Started

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm start

# Run on iOS
pnpm ios

# Run on Android
pnpm android

# Run on Web
pnpm web
```

## Features

- 📱 All 11 components showcased
- 🎨 Light and dark theme toggle
- 🔍 Interactive examples
- 📋 Copy-paste code snippets
- 🎭 Live component playground
